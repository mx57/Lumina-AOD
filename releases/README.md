# Lumina AOD Studio — Сборки APK (Релиз v3.0 • 2026 Edition)

В данной директории расположены готовые к установке подписанные установочные пакеты **Lumina AOD Studio v3.0** для устройств с экранами AMOLED / OLED (Android 7.0+ API 24–36). При каждой новой сборке проекта (`gradle :app:assembleDebug`) старые `.apk` файлы автоматически удаляются и заменяются свежими сборками.

| Архитектура процессора | Имя файла APK | Описание |
| :--- | :--- | :--- |
| **ARMv8 (64-bit)** | `LuminaAOD-v3.0-arm64-v8a.apk` | Основная сборка для современных смартфонов на базе `arm64-v8a` |
| **ARMv7 (32-bit)** | `LuminaAOD-v3.0-armeabi-v7a.apk` | Совместимая сборка для устройств с 32-битной архитектурой `armeabi-v7a` |
| **Контрольные суммы** | `SHA256SUMS.txt` | Хеш-суммы SHA-256 для проверки целостности пакетов |

## Что нового в релизе v3.0 (2026 Edition)
- **Глобальный поиск любого города мира и реальный прогноз (Open-Meteo API)**: онлайн-поиск городов и населенных пунктов с координатами и странами, сохранение списка избранных городов, реальный почасовой график на 24 часа, прогноз на 7 дней, давление в мм рт. ст., порывы ветра и вероятность осадков.
- **11 форм Динамического Острова**: добавлены 5 новых форм (*Матричное Табло*, *Двойные Крылья*, *Звездная Капля*, *Вырез-Монобровь*, *Спектр-Волна*) вдобавок к *Капсуле*, *Разделенной Капле iPhone Pro*, *Cyber-Гексагону*, *Жидкой Сфере*, *Ультра-Нити* и *Скрытому Контуру*.
- **Появление только при уведомлениях и событиях**: настраиваемый режим видимости с автоматическим скрытием в покое и таймером авто-сворачивания (3–30 сек).
- **Открытие родительского приложения по тапу**: тап раскрывает Остров, повторный тап или кнопка **«Открыть»** мгновенно запускает приложение-источник уведомления/плеера (`PendingIntent` / `PackageManager`), а долгий тап сворачивает и скрывает Остров.
- **Бегущая строка 120Hz (Marquee Ticker) и Мини-Хаб**: плавная бегущая строка для пушей, треков, сводок погоды и своего текста с настройкой скорости и шрифта + встроенный быстрый фонарик (`CameraManager`), живая телеметрия CPU/RAM/Батареи, эквалайзер и точка приватности камеры/микрофона.
