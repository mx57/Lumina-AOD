# Lumina AOD Studio — Сборки APK (Релиз v2.0 • 2026 Edition)

В данной директории расположены готовые к установке подписанные установочные пакеты **Lumina AOD Studio v2.0** для устройств с экранами AMOLED / OLED (Android 7.0+ API 24–36). Сборки в папке `releases/` автоматически обновляются при каждой сборке проекта (`gradle :app:assembleDebug`).

| Архитектура процессора | Имя файла APK | Описание |
| :--- | :--- | :--- |
| **ARMv8 (64-bit)** | `LuminaAOD-v2.0-arm64-v8a.apk` | Основная сборка для современных смартфонов на базе `arm64-v8a` |
| **ARMv7 (32-bit)** | `LuminaAOD-v2.0-armeabi-v7a.apk` | Совместимая сборка для устройств с 32-битной архитектурой `armeabi-v7a` |
| **Контрольные суммы** | `SHA256SUMS.txt` | Хеш-суммы SHA-256 для проверки целостности пакетов |

## Что нового в релизе v2.0 (2026 Edition)
- **Автономная служба AOD и системный оверлей**: фоновая работа через `LuminaAodForegroundService`, авто-пробуждение при выключении экрана, подключении зарядки и входящих уведомлениях, а также вывод поверх экрана блокировки и всех окон (`WindowManager`).
- **Центр Разрешений Android**: интерактивная диагностика и быстрая выдача всех 4 системных разрешений прямо из приложения.
- **Перемещаемый Динамический Остров (Drag-and-Drop)**: свободное перетаскивание пальцем с магнитной центровкой (`X = 0 dp`), 7 пресетов якорей, микро-калибровка с шагом `0.5 dp` и 6 геометрических форм (*Капсула*, *Разделенная Капля iPhone Pro*, *Cyber-Гексагон*, *Жидкая Сфера*, *Ультра-Нить*, *Скрытый Контур*).
- **Гибридный Белый и Черный список приложений**: фильтрация уведомлений по всем установленным приложениям с индивидуальными цветами LED, приоритетом и авто-пробуждением экрана.
- **Жидкий морфинг 120Hz и 3D-параллакс**: вязкие метаболы при отделении от камеры, 3D-наклон от акселерометра/гироскопа, шейдерное неоновое свечение и парящие искры по краям экрана.
