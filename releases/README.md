# Lumina AOD Studio — Сборки APK (Релизы v1.0)

В данной директории расположены готовые к установке подписанные установочные пакеты **Lumina AOD Studio v1.0** для устройств с экранами AMOLED / OLED (Android 7.0+ API 24–36):

| Архитектура процессора | Имя файла APK | Описание |
| :--- | :--- | :--- |
| **ARMv8 (64-bit)** | `LuminaAOD-v1.0-arm64-v8a.apk` | Основная сборка для современных смартфонов на базе `arm64-v8a` |
| **ARMv7 (32-bit)** | `LuminaAOD-v1.0-armeabi-v7a.apk` | Совместимая сборка для устройств с 32-битной архитектурой `armeabi-v7a` |
| **Контрольные суммы** | `SHA256SUMS.txt` | Хеш-суммы SHA-256 для проверки целостности пакетов |
